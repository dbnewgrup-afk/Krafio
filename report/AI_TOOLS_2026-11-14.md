## 3. Kontrol Admin

**Admin → AI → AI Tools** (`/admin/ai/tools`):
- Status provider teks, gambar, dan video, plus tombol **Uji AI teks** (menampilkan model, waktu respons, dan contoh jawaban).
- Per fitur: saklar aktif/nonaktif (fitur nonaktif hilang dari panel user, dan API menolak dengan `tool_disabled`), pemakaian bulan ini, serta tombol **Atur**:
  - label dan deskripsi,
  - biaya per unit dan batas part/item,
  - field yang ditampilkan (field wajib selalu tampil),
  - nilai default tiap opsi.
- Tautan ke prompt fitur di **Prompt Library** (`tool.<fitur>.system` dan `tool.<fitur>.instruction`; prompt gambar/video di `image.*`/`video.*`).
- Lencana repo GitHub yang dipakai fitur tersebut (lisensi, metode, catatan).

**Admin → AI → Provider** sekarang mendukung driver `openai_compatible`, `openai_images`, `fal`, `replicate`, `comfyui`, dan `custom_http`.

## 6. Perubahan lingkungan lokal

- `krafio-start` sekarang menjalankan MySQL, **Ollama**, server PHP (4 worker, batas unggah 200 MB), **queue worker AI**, dan Vite. Job AI tidak lagi diproses "inline", karena naskah 2 menit sebelumnya membekukan seluruh website.
- Tambahan di `~/.krafio-tools`: Ollama 0.40 + `qwen2.5:3b`, FFmpeg/ffprobe 6.1.1, dan `php/php.ini` (`upload_max_filesize=210M`, `post_max_size=220M`).
- Setelah mengubah kode backend, **restart worker**: `pkill -f "queue:work"; krafio-start`.

## 7. Wajib untuk server produksi

1. `apt install ffmpeg`, plus ekstensi PHP `imagick` (atau `gd`).
2. Queue worker (Supervisor/systemd): `php artisan queue:work --queue=ai,default --timeout=1800 --tries=1`, dengan `KRAFIO_JOBS_INLINE=false`.
3. Batas unggahan: PHP-FPM `upload_max_filesize=210M`, `post_max_size=220M`; Nginx `client_max_body_size 220m;`.
4. Isi API key provider teks utama. Untuk gambar/video, tambahkan provider `openai_images`/`fal`/`replicate` beserta model-nya.
5. `php artisan migrate` (migrasi `2026_11_14_000200_ai_tools_prompts`). `php artisan krafio:ai-local` hanya untuk server yang juga menjalankan Ollama.

## 8. Belum dikerjakan (di luar AI Tools)

- **Integrasi media sosial:** callback OAuth belum ada dan butuh aplikasi resmi Meta/TikTok (audit B2).
- **Hosting website user** di subdomain/domain kustom (audit B1).
- Clipper berbasis transkrip + LLM (tahap AutoClip berikutnya; butuh Whisper). Saat ini pemilihan momen berbasis energi audio dan perubahan adegan.
- Ekspor DOCX/PPTX/XLSX (Wordcraft/Deckcraft/Gridcraft). Saat ini ekspor `.md`/`.txt`/`.csv` dilakukan di browser.

## 10. Putaran 2 — tanpa hasil contoh, medsos, Postiz, fitur dari repo, Clipper fleksibel

### 10.1 Tidak ada lagi "hasil contoh" sebelum/tanpa generate
| Sebelumnya | Sekarang |
|---|---|
| Tanpa penyedia gambar/video, job "selesai" dengan **foto stok** (roti, kopi) seolah hasil AI. | Dihapus. Tanpa penyedia, job **ditolak sebelum kuota/kredit dipotong** (`ai_unavailable`); bila penyedia hilang di tengah proses → job gagal + kredit kembali. |
| Tool teks tanpa penyedia mengembalikan kerangka contoh. | Dihapus (sama seperti di atas). |
| Studio menampilkan gambar mockup “Hasil” dan ilustrasi bertuliskan “Belum ada proyek”. | Keadaan kosong netral: ikon + “Belum ada hasil — hasil akan muncul setelah Anda menekan Generate”. Tombol Generate nonaktif + pesan jelas bila fitur belum aktif. |
| Website baru berisi teks pengisi (“Tuliskan layanan…”). | Isi kosong; petunjuk menjadi placeholder editor (tidak ikut terbit). |
| Akun demo berisi job uji & foto stok. | Dibersihkan (job, unggahan, berkas hasil, kuota). Test otomatis kini memakai storage palsu sehingga tidak mengotori storage lokal. |

### 10.2 Video Clipper — lancar & fleksibel
- Unggah langsung saat file dipilih; **durasi & resolusi diukur server (ffprobe)** → estimasi kredit dari durasi asli (field “durasi sumber” dihapus).
- Mode **otomatis** (1–10 klip, 5–180 dtk, suara paling ramai / perubahan adegan / merata, jeda minimal) atau **manual** (`0:30-1:05, 2:10-2:40`, maks 10).
- Tata letak **crop / latar blur / bingkai hitam**, 720p/1080p, **fade**, **judul/hook di video** (3 detik pertama atau sepanjang klip), **thumbnail** per klip, unduh satu/semua.
- Penanganan tepi: video tanpa suara → otomatis pakai perubahan adegan/merata (dengan catatan), video lebih pendek dari panjang klip → 1 klip penuh, rentang tidak valid dibuang.
- Diuji: 4 skenario (landscape 2 mnt, portrait tanpa audio, WebM 8 dtk, mode manual) + browser end-to-end.

### 10.3 Integrasi media sosial (login sendiri via popup → REST callback)
- 7 platform: Instagram, Facebook, Threads, TikTok, YouTube, LinkedIn, X. Admin mengisi aplikasi OAuth resmi per platform; halaman admin menampilkan URL callback untuk didaftarkan.
- Alur: *Hubungkan* → popup ke halaman login resmi → callback `GET /api/social/callback/{platform}` (state sekali pakai, PKCE untuk X) → token terenkripsi + data profil (nama, @username, foto, pengikut/subscriber/postingan) → popup memberi tahu panel lalu tertutup; fallback redirect bila popup diblokir. *Sinkronkan* memperbarui data & token (refresh otomatis; gagal → status kedaluwarsa).
- **Postiz**: hubungkan kanal lewat halaman connect Postiz (kanal milik pengguna lain tidak bisa diklaim), lalu **Buat posting & jadwal** (sekarang / jadwal / draf) + riwayat posting. Tombol **Kirim ke medsos** di hasil caption/copy.
